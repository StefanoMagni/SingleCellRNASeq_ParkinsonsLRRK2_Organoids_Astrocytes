# SingleCellRNASeq_ParkinsonsLRRK2_Organoids_Astrocytes

This folder contains the python codes developed to perform the analysis of single cell RNA-Seq data for the published manuscript: "LRRK2-G2019S impairs astrocyte differentiation and triggers a senescence-like phenotype in Parkinson’s disease models". This manuscript is in press at the journal: npj Parkinson's Disease, and it is publicly available at the link: https://doi.org/10.1038/s41531-026-01472-y. The codes collected here have been developed by Stefano Magni (stefano.magni01@gmail.com).
